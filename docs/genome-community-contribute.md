# Contributing a Community Genome

[English](genome-community-contribute.md) · [简体中文](genome-community-contribute.zh-CN.md)

[`examples/genomes/`](../examples/genomes/) is the community shelf for Genomes:
one self-contained directory per Genome, installable straight from a clone of
this repo, contributed by pull request. This page is the full guide; the
[README](../README.md#community-genomes) has the short version.

## Trying one

From a clone of this repo, with `rsih` installed:

```bash
rsih genome install examples/genomes/paperlab
rsih :paperlab
```

| Genome | What it is |
| --- | --- |
| [`paperlab`](../examples/genomes/paperlab/) | run paper experiments — scout real datasets and checkpoints, bootstrap a reproducible environment, operate long runs from observed state |

## What a contribution must satisfy

1. **One self-contained directory**, `examples/genomes/<name>/`: manifest,
   component configs, contracts, skills, extensions — everything the Genome
   references lives inside the directory. A reference that leaves the bundle
   breaks the moment the Genome is installed somewhere else, and validation
   catches it: run in a fresh clone of this repo, `validate` fails on any path
   that assumes your machine's layout.
2. **Contracts inlined.** A manifest generated by `gee` points contracts at the
   `harness-rsi` sibling inside `~/.rsih/genomes/`. That sibling does not exist
   in `examples/genomes/`, so copy the referenced contract files into your
   bundle (e.g. `contracts/<id>.dev.md`) and point the manifest at them.
3. **A unique `genome_id`.** The directory name is an address, not an identity
   — anyone can name a Genome `paperlab`. The `genome_id` travels inside the
   manifest, and it is what lets a seed refresh tell "an older copy of this
   same Genome" apart from "a different Genome that happens to share the
   name": the first is refreshed, the second is never touched.
4. **`rsih genome validate examples/genomes/<name>` passes** — run from a clone
   of this repo, before opening the PR.
5. **No private residue.** A Genome is distilled from your own transcripts;
   strip absolute paths, intranet hostnames, and likely secrets first.
   Everything in the directory is public the moment the PR merges.
6. Open the PR.

## Hand-written or GEE-generated

Both land in exactly the same shape. `gee` writes a complete bundle into
`~/.rsih/genomes/<name>/`: copy that directory in, inline its contracts
(rule 2), and validate. Hand-writing starts from the
[component protocol](genome/README.md); [`paperlab`](../examples/genomes/paperlab/)
— the shipped example — is the one to copy from.

Three habits worth keeping either way — declare only the components you
actually configure, prefer `append_system_prompt` over replacing Pi's prompt,
and decide `resources.isolate` on purpose instead of leaving it unset.
